# AGENTS.md

Static, single-page marketing site for Carpintería El Roble (custom woodworking, Buenos Aires). No framework, no build step, no package manager, no tests. Three hand-written files plus images.

## Preview

There is no dev server, bundler, or npm script. Open `index.html` directly in a browser, or serve the folder with any static server. Do not add tooling or run `npm install` — the site is intentionally dependency-free.

## Layout

- `index.html` — the entire page, one `<section>` per block. Copy is Spanish (`lang="es"`).
- `styles.css` — all styles, authored as a **single minified line** (~14 KB).
- `script.js` — classic (non-module) script loaded at the end of `<body>`. Only mobile menu, scroll-reveal, stat counters, and footer year.
- `assets/` — images. Only the `.png` files referenced in `index.html` are live; the `.jpg` files and everything under `assets/source/` are unused source art.

## Gotchas

- `styles.css` is one line on purpose. Append rules to that same line; do not pretty-print or reformat it (noisy huge diffs, and line-based readers truncate it). Read it with a raw/streaming method, not a single-line viewer.
- Scroll-reveal is gated on a `js` class: CSS hides `.js .reveal`, and `script.js` adds `.visible` via `IntersectionObserver` (queries `.reveal` once at load). The `js` class comes from an inline `<script>` in `<head>`; the `script.js` tag's `onerror` removes it, so content stays visible if the script fails to load. New content must carry `class="reveal"` and be in the DOM at load to be observed.
- The WhatsApp number is a placeholder `5490000000000` and appears **twice** in `index.html` (contact CTA and floating button). Replace both when wiring the real number; format is country code with no `+`, spaces, or dashes.
- `body::after` is a full-viewport film-grain overlay (`z-index:99`, `mix-blend-mode:overlay`, inline SVG noise). It renders above everything — anything meant to sit on top of the grain needs a higher `z-index`.
- The two manifesto stats animate from `[data-count]` / `data-suffix` attributes read by `script.js`; keep the attribute and the literal fallback text in sync.
- Photos share a warm colour grade applied via `filter` on `.hero-image`, `.feature-photo img`, `.card img`, `.contact-image`. New photos inherit it; do not add a second `filter`.
- Theme tokens live in `:root`: `--ink`/`--ink-soft`, `--paper`/`--paper-2`/`--paper-3`, `--warm` (sienna accent), `--brass`/`--brass-soft` (gold accent), `--bone` (text on dark), `--line`, plus the `--display`/`--sans`/`--mono` font vars. There should be **no hardcoded hex outside `:root`**. The three fonts load from Google Fonts via `<link>` in `index.html`.
- `script.js` is defensive: `#year` is null-guarded and the menu button/nav use optional chaining, so removing those elements will not throw.
- Git: repo at `github.com/Taxgab/El-roble-Landing`, branch `main`. No CI, lint, or formatter config. `.atl/` is gitignored (auto-generated by gentle-ai); do not hand-edit it.

## Conventions

- Keep user-facing copy and `aria-label`s in neutral Spanish.
- Sections use a numbered kicker pattern (`01 El oficio`, `02 Proyectos a medida`, …); keep numbering consistent when inserting sections.
