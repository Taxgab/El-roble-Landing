# Carpintería El Roble

Landing page de una sola página para Carpintería El Roble, diseñada para presentar trabajos reales y convertir consultas en WhatsApp.

## Incluye

- Portfolio filtrable de proyectos.
- Servicios, materiales, proceso de trabajo e historia desde 1978.
- Navegación móvil y diseño responsive.
- Enlaces a Instagram y CTA de WhatsApp.

## Publicación local

Abrí `index.html` en un navegador. No requiere instalación ni proceso de compilación.

## Antes de publicar

Reemplazá el número de ejemplo `5491131370003` en `index.html` por el WhatsApp comercial real, con código de país y sin `+`, espacios ni guiones.
